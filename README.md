# LMF — формат и приложения

## Формат LMF v1

Бинарный контейнер для набора изображений одинакового размера,
которые логически расположены вплотную друг к другу сверху вниз.
Внутри нет исходных PNG/JPG/WebP — все кадры декодируются в сырые
пиксели RGBA и сжимаются одним блоком zlib (level 9), что даёт
максимальное сжатие без потери качества (lossless).

```
смещение  тип       поле
0         4 байта   magic "LMF1"
4         u8        версия (=1)
5         u32 LE    количество кадров N
9         u32 LE    ширина W
13        u32 LE    высота одного кадра H
17        u8        формат пикселя (0 = RGBA8888)
18        u64 LE    длина сжатых данных
26        ...       zlib-сжатые пиксели всех кадров подряд
```

Итоговое изображение — это один буфер `W × (H·N)`, кадры идут
подряд в порядке добавления. При чтении их не нужно склеивать
отдельно — расшифрованный буфер уже готов к отрисовке как единое
изображение.

Zlib выбран потому, что он совместим "из коробки" между Dart
(`package:archive`) и Rust (`miniz_oxide`) без дополнительных
зависимостей.

## Android-приложение (Flutter/Dart)

Путь: `android_app/`.

- `lib/lmf_format.dart` — кодек LMF (упаковка/распаковка).
- `lib/screens/home_screen.dart` — выбор фото (сортировка по числу
  в конце имени файла), сборка `.lmf`, шеринг результата.
- `lib/screens/reader_screen.dart` — рендер `.lmf` через
  `decodeImageFromPixels` (без промежуточного PNG).
- `lib/main.dart` — Material You (Android 12+, `dynamic_color`),
  тёмная тема по умолчанию (чёрный/тёмно-серый) + светлая тема.

Сборка:
```
cd android_app
flutter pub get
flutter run          # или flutter build apk
```

## Web-ридер (Rust → WebAssembly)

Путь: `web_reader/`.

- `src/lib.rs` — парсер LMF (`decode_lmf`), экспортируется через
  `wasm-bindgen`.
- `index.html`, `style.css`, `main.js` — минимальный тёмный интерфейс:
  одна кнопка «Открыть файл» + drag-and-drop, весь остальной текст
  отсутствует.

Сборка:
```
cd web_reader
wasm-pack build --target web --out-dir pkg
# затем раздать index.html, style.css, main.js и pkg/ любым
# статическим сервером, например:
python3 -m http.server 8080
```

## Формально поддерживаемые входные форматы (Android-упаковщик)

PNG, JPEG, WebP, BMP, GIF, HEIC/HEIF (через `package:image`) —
любые изображения должны совпадать по ширине и высоте.
