# LMF — формат и приложения

## Формат LMF v2

Бинарный контейнер для набора изображений одинакового размера,
которые логически расположены вплотную друг к другу сверху вниз.
Внутри нет исходных PNG/JPG/WebP — все кадры декодируются в сырые
пиксели RGBA, затем каждая строка пикселей прогоняется через
адаптивную предиктивную фильтрацию (тот же набор фильтров, что
использует сам PNG: None/Sub/Up/Average/Paeth — для каждой строки
выбирается тот, что даёт наименьшие по модулю остатки), и только
после этого результат сжимается одним блоком zlib (level 9).
Фильтрация полностью обратима (lossless) и на фото даёт кардинально
лучшее сжатие, чем сырой zlib по пикселям, — потому что zlib гораздо
эффективнее давит небольшие построчные остатки, чем шум реальных
пикселей.

```
смещение  тип       поле
0         4 байта   magic "LMF1"
4         u8        версия (=2)
5         u32 LE    количество кадров N
9         u32 LE    ширина W
13        u32 LE    высота одного кадра H
17        u8        формат пикселя (0 = RGBA8888)
18        u64 LE    длина сжатых данных
26        ...       zlib-сжатые отфильтрованные строки всех кадров подряд
```

После распаковки zlib каждый кадр — это `H` строк вида
`[байт типа фильтра][W×4 отфильтрованных байт]`; типы фильтров и
формулы 1:1 совпадают с PNG (RFC 2083, раздел «Filtering»).

Итоговое изображение — это один буфер `W × (H·N)` после снятия
фильтрации, кадры идут подряд в порядке добавления. При чтении их
не нужно склеивать отдельно — расшифрованный буфер уже готов к
отрисовке как единое изображение.

Zlib выбран потому, что он совместим "из коробки" между Dart
(`package:archive`) и Rust (`miniz_oxide`) без дополнительных
зависимостей.

## Android-приложение (Flutter/Dart)

Путь: `android_app/`.

- `lib/lmf_format.dart` — кодек LMF (упаковка/распаковка). При сборке
  фото разного размера автоматически приводятся к размеру первого
  снимка центрированным кропом (без искажения пропорций) — жёсткое
  требование "все кадры одного размера" действует только для самого
  формата и его чтения, пользователю ничего вручную подгонять не нужно.
  `encode()` принимает `onProgress`, чтобы UI мог показать реальный
  прогресс по этапам (обработка каждого фото + сжатие).
- `lib/screens/home_screen.dart` — выбор фото (сортировка по числу
  в конце имени файла), сборка `.lmf`, шеринг результата.
- `lib/screens/reader_screen.dart` — рендер `.lmf` через
  `decodeImageFromPixels` (без промежуточного PNG).
- `lib/main.dart` — Material You (Android 12+, `dynamic_color`),
  тёмная тема по умолчанию (чёрный/тёмно-серый) + светлая тема.

Сборка:
```
cd android_app
flutter pub get
flutter create --platforms=android --project-name lmf_app .   # один раз: добавляет android/
rm -rf test   # шаблонный тест ссылается на MyApp/flutter_test, у нас его нет
# file_picker тянет flutter_plugin_android_lifecycle, которому нужен
# compileSdk/targetSdk 36 — если шаблон Flutter поставил меньше,
# поднимите вручную в android/app/build.gradle.kts. Также держите
# сам file_picker на версии, собранной под compileSdk 36+ (см. pubspec.yaml) —
# иначе Gradle упадёт на checkReleaseAarMetadata даже с compileSdk=36 в приложении.
flutter run          # или flutter build apk
```

> В репозитории нет папки `android/` — она генерируется командой
> `flutter create` (в CI это делается автоматически). Один раз
> сгенерировав её локально, можно закоммитить в репозиторий, чтобы
> не пересоздавать каждый раз.

## Web-ридер (Rust → WebAssembly)

Путь: `web_reader/`.

- `src/lib.rs` — парсер LMF (`decode_lmf`), экспортируется через
  `wasm-bindgen`.
- `index.html`, `style.css`, `main.js` — минимальный тёмный интерфейс:
  одна кнопка «Открыть файл» + drag-and-drop, весь остальной текст
  отсутствует.

Сборка:
```
cd web_reader
wasm-pack build --target web --out-dir pkg
# затем раздать index.html, style.css, main.js и pkg/ любым
# статическим сервером, например:
python3 -m http.server 8080
```

## Формально поддерживаемые входные форматы (Android-упаковщик)

PNG, JPEG, WebP, BMP, GIF, HEIC/HEIF (через `package:image`) —
любые изображения должны совпадать по ширине и высоте.
